# Tea-Borgs — presentation website

A responsive, single-page presentation site built with plain HTML, CSS and JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or open it directly in a browser.
3. An internet connection is needed for Google Fonts and the Unsplash photos.

## Included interactions

- Floating responsive navbar with mobile menu
- Active navigation indicator based on the visible section
- Scroll progress bar
- Scroll-reveal animations
- Count-up stats
- Project category filters
- Hover transitions and responsive layouts
- Reduced-motion accessibility support

## Before publishing

- Replace the demo project descriptions and Unsplash photos with real Tea-Borgs content and photos.
- Confirm the contact email in `index.html`.
- Check all text, dates and team details with the club.
